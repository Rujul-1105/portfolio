# Changelog

Format: `[YYYY-MM-DD] — version — summary`

| Date | Version | Change |
|---|---|---|
| 2026-09-30 | v1.0 | Initial build. Next.js 15 + Tailwind v4 + Motion + TS. Sections: Hero / Now / Selected Work / Experience. Editorial-minimal aesthetic with Instrument Serif / Inter Tight / JetBrains Mono. JSON-driven content via `data/*.json`, Zod-validated at build time. Light + dark theme toggle persisted in localStorage. |
| 2026-09-30 | v1.1 | Aesthetic upgrade to "Swiss × Cybercore". Added `decor/` components (`GridPattern`, `GeometricAccent`, `TerminalCursor`, `NoiseOverlay`). New tokens (`--color-neon`, glow, terminal). Hero redesigned with status line, drifting geometric ring + arc, dot grid backdrop. Section labels upgraded (bigger numbers, hover-glow). Project titles, Now headline, Experience role, Footer bio switched to italic display. |
| 2026-09-30 | v1.1a | Light theme warmed to bohemian palette (`#efe5d2` paper, terracotta accent, sage/rose secondary tones). Dark theme adjusted to match. Navbar handle now links to Twitter. Added `twitter` + `github` fields to `SiteConfig`. |
| 2026-09-30 | v1.1b | Added GitHub Activity section (`04 — Activity`). 53×7 contribution grid with 5 intensity levels, deterministic mock data seeded per username. Palette tokens `--color-act-0..4` tuned per theme. Real API integration path documented in `lib/activity.ts`. |
| 2026-09-30 | v1.1c | Tightened vertical rhythm across all sections (`Section`, `NowSection`, `NowBlock`, `ProjectRow`, `ExperienceRow`, `ActivitySection`, `ProjectsSection`). Hero geometric accents reduced in size and opacity (`text-line/40`, 420–520px instead of 640–820px). Section outer padding reduced from `py-24..40` to `py-20..32`. |
| 2026-09-30 | v1.2 | Added `ProjectHoverPreview` primitive — featured project cover gets a hover overlay with title + "Visit Live ↗" CTA + secondary link chips. Opt-in iframe preview via new `previewUrl` field on Project. Compact rows get a left neon accent line on hover + visible ↗ + background tint. |
| 2026-09-30 | v1.2.1 | Switched display font from Newsreader → Fraunces (variable serif with optical sizing). Dropped italic weight on Fraunces to work around a next/font quirk. `docs/` directory created with this changelog, `DECISIONS.md`, `CONTENT.md`, `ROADMAP.md`. Git repository initialized, v1.0+ snapshot committed. |
| 2026-09-30 → 2026-10-01 | v2 (branch `v2`, archived) | Tried a black + red superteam.fun-inspired redesign on a separate `v2` branch. User feedback: "your v2 is trash." After a full iteration that pulled in TextRain, BracketButton, SectionCorners, dotted wordmark, and the dot-red period accent, user decided to return to v1 instead. v2.1 final state preserved at commit `3d9273c` on the `v2` branch. v1 (v1.2) is the active working version on `main`. |
| 2026-10-01 | v1.3 | **Unified project hover preview.** Removed the featured + compact row split — every project now uses the same `ProjectCard` layout in a 2-column grid. `ProjectHoverPreview` updated to show an iframe of the destination on hover (when `previewUrl` is set), with image-fade fallback if the iframe blocks embedding. Removed `ProjectRow.tsx`. All four placeholder projects now seed `previewUrl` (pointing to embeddable Wikipedia pages) so the feature is visible in the demo. |
| 2026-10-01 | v1.4 | **Theme toggle is now a proper icon button** (sun/moon SVG inside a square `border` button) — was previously a mono text button. **Mobile menu added** to TopNav — inline nav links hide on `<md`, replaced by a hamburger that opens a right-side slide-in panel with the nav, theme toggle, and CTA button. Body scroll is locked while the panel is open, Escape closes it. **Mobile responsiveness audit** — hero `min-h` reduced from `90vh` to `70vh md:90vh`; hero padding reduced; geometric accent sizes and opacities reduced on mobile; section padding reduced (`py-16 md:py-24 lg:py-32`). |
| 2026-10-01 | v1.4a | **Added About section** between Hero and Now with `site.bio` rendered in display italic + a 3-up values strip (Calm / Considered / Durable). Section indexes renumbered: About=01, Now=02, Experience=03, Projects=04, Activity=05. **Moved Experience above Projects** so the section order is Hero / About / Now / Experience / Projects / Activity. **Removed "Subscribe by RSS" link** from `data/now.json` `links[]` (it pointed to a non-existent `/feed.xml`). |
| 2026-10-01 | v1.5 | **TopNav trimmed** — removed the standalone `Twitter` text link and the `Get in touch ↗` button. The `@yourhandle` label already links to Twitter, so the extra link was redundant. Right side of the nav now shows only the theme toggle (and the hamburger on mobile). **Added Josefin Slab** as a 5th font family — applied to the **Now section headline** (large display slab with neon period) and the **Experience section role titles** (per-row, scales with viewport). Font wired into Tailwind via `--font-slab` + `.font-slab` utility. **Design polish** — Added a small neon dot before the month label in Now ("● September 2026"), tightened About section grid gap, added hover bg transition on values strip cells. |
| 2026-10-01 | v1.6 | **Dropped the mobile menu toggle entirely.** The slide-in panel was rendering the header (`MENU` + close X) but the nav items below were not appearing — items array was passed but the panel layout was failing on small viewports. Rather than keep debugging the broken slide-in, deleted `MobileMenu.tsx` and removed its import from `TopNav`. On mobile the nav now shows logo + theme toggle only (the inline `<ul>` of nav links stays hidden on `<md` via `hidden md:flex`). Users reach sections by scrolling or via the social handles in the footer. Also adjusted padding (`px-4 md:px-10`) so the bar breathes on narrow viewports. |
