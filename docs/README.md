# Portfolio — Docs Index

This directory tracks every meaningful change to the portfolio site. Update these files in the same commit that changes the code.

| File | Purpose |
|---|---|
| [`CHANGELOG.md`](./CHANGELOG.md) | Chronological log of every change (added / changed / fixed / removed). Append a row per commit. |
| [`DECISIONS.md`](./DECISIONS.md) | Why we chose X over Y — design tokens, fonts, libraries, layout decisions. Append a row whenever a decision is made. |
| [`CONTENT.md`](./CONTENT.md) | What the user needs to provide to swap placeholder JSON for real data. |
| [`ROADMAP.md`](./ROADMAP.md) | Upcoming versions, planned features, open questions. |

**Cadence** — when you (Claude) change the site, append to **CHANGELOG** + **DECISIONS** in the same response. When the user provides new content, append to **CONTENT** and update **ROADMAP** when a version is approved/discarded.
